# বাজার দর \| BazarDor

## 📌 About the Project

**বাজার দর (BazarDor)** is a web application that helps people check the
prices of everyday essentials in one place. Browse common grocery
categories, review listed prices, and quickly see which products have
increased or decreased in price.

The goal is to make everyday market-price information easier to explore
and help users make more informed shopping decisions.

## 🛠️ Technologies Used

-   **Next.js** --- React framework for the web application
-   **React** --- Component-based user interface
-   **Tailwind CSS** --- Responsive styling and UI design
-   **MongoDB** --- Database for application data
-   **Better Auth** --- Authentication and account management
-   **Vercel** --- Deployment and hosting

## ✨ Key Features

1.  **Everyday Product Prices** --- Browse prices for common essentials
    such as rice, lentils, oil, vegetables, fish, meat, eggs, dairy, and
    spices.
2.  **Category-Based Browsing** --- Explore products by category to find
    relevant items more easily.
3.  **Price Change Indicators** --- Quickly identify products marked as
    having increased or decreased in price.
4.  **Market-Price Overview** --- View product names, prices, and
    measurement units in a single, convenient place.
5.  **User Authentication** --- Sign-in and sign-up options for user
    accounts.

Market prices can change by location, seller, and date. Treat displayed
prices as indicative information and confirm the current price with your
local market before making a purchase.
